# FINAL FANTASY RESONANCE トレーナー

[English](README.md) | [한국어](README.ko.md) | **日本語**

Steam版 FINAL FANTASY RESONANCE (シングルプレイ) 用のトレーナーです。実行中のゲームのメモリ上にあるセーブデータとデータテーブルの値を読み書きします。ゲームのファイルや実行コードには手を加えません。

## 動作環境

| | |
|---|---|
| OS | Windows 10 / 11、**64ビット (x64)** — Windows 11 で動作確認 |
| ゲーム | **FINAL FANTASY RESONANCE Steam版** (シングルプレイ) |
| 追加ソフト | `FFR-Trainer.exe` には不要です。Python はソースから実行する場合のみ必要です。 |

- 他のプラットフォームや Steam 以外のストア版には対応していません。
- 32ビット版 Windows と ARM 版 Windows には対応していません。
- ゲームが起動していて、セーブがロードされている状態でないとトレーナーは接続できません。

## はじめに

1. ゲームを起動し、**セーブをロード**します (タイトル画面より先へ進めます)。
2. `FFR-Trainer.exe` を実行します。
3. ウィンドウ上部に `接続済み (PID …)` と表示されれば準備完了です。
   - 初回はアイテム名やキャラクター名を読み込むため数秒かかります。2回目以降はすぐに表示されます。
   - ゲームより先にトレーナーを起動した場合は、ゲームを起動してから **ゲームに接続** を押してください。

| 上部のボタン | 機能 |
|---|---|
| ゲームに接続 | ゲームを探し直して接続します。ゲームを再起動した後に押します。 |
| 更新 | 表示中の値をゲームから読み直します。 |
| 名前を再読込 | アイテム名・キャラクター名をゲームから読み直します。パッチ後やゲームの言語を変えた後に名前がおかしいときに使います。 |
| 言語メニュー | 画面の言語を 한국어 / English / 日本語 から選びます。すぐに反映され、次回の起動時も維持されます。 |

名前は、ゲームが動作している言語で表示されます。

## 最初に知っておくこと

- 変更を残すには **ゲーム内でセーブ** してください。念のため既存のセーブを上書きせず、**別のスロットにセーブ** することをおすすめします。
- 変更がゲーム画面にすぐ反映されないときは、**メニューを開き直して** ください。
- `バトル` タブの値 (ドロップ率、戦闘計算の数値) はセーブに残りません。**ゲームを終了すると元に戻る** ため、起動のたびに適用し直す必要があります。
- リストでは **行をクリックすると選択、もう一度クリックすると解除** されます。複数の行を順にクリックすれば複数選択できます。

## タブごとの機能

### 一般

| 項目 | 説明 |
|---|---|
| 所持金 | 値を入力して **適用**。**最大** は 9,999,999 ギル。 |
| 所持金を固定 | チェック中は所持金が入力した値より下がりません。 |
| 難易度 | Easy / Normal / Expert から選んで **適用**。 |
| ランダムエンカウントを無効化 | オンの間、フィールドで敵と遭遇しなくなります。 |
| エンカウント率 | 0〜300% のスライダー。100% が標準、300% は3倍の頻度。**100%に戻す** で復元。 |

- エンカウント関連の機能は **フィールドにいるときだけ** 適用されます。スイッチの横に `適用中` または `フィールド待機中` と表示されます。
- ストーリーイベントの戦闘やボス戦は防がないものと思われます。
- 「無効化」はスライダーより優先されます。

### キャラクター

リストでキャラクターをクリックすると、下の編集欄に現在の値が入ります。

| 項目 | 説明 |
|---|---|
| レベル | 入力したレベルに必要な経験値に合わせます。 |
| 経験値 | 経験値を直接入力します。 |
| 現在HP / MP | 現在のHP・MPを変更します。 |
| ステータス永続ボーナス | 最大HP、最大MP、攻撃、防御、知性、精神、素早さに加算される永続ボーナスです。 |

- レベル・経験値を変更した後は、**セーブしてロードし直すか、戦闘を1回** 行うと能力値に反映されます。

### アイテム

- **表示**: 所持中 / すべて / 消耗品 / 武器 / 防具 / アクセサリー / だいじなもの / アーティファクト
- **検索**: 名前の一部またはIDで探します。
- **選択項目に適用**: 選択したアイテムの数量を入力した値 (1〜99) にします。
- **所持中の消耗品すべてに適用**: 持っている消耗品をまとめて設定します。

**未所持アイテムの登録** — 薄い文字で表示されているのが未所持のアイテムです。選択して適用すると新規登録されますが、条件があります。

- 右上の **「新規登録できる空きスロット」** の数だけ登録できます。
- セーブをロードした直後は通常 **0** です。
- 空きスロットを作るには、ゲーム内で **まだ持っていない種類のアイテムを1つ** 入手してください (ショップで購入など)。するとゲームがインベントリを拡張し、空きスロットが数十個できます。
- だいじなものとアーティファクトは、数量が常に1で登録されます。
- **だいじなもの** はストーリー進行の条件に使われることがあるため、登録前に確認ダイアログが表示されます。先に持っているとイベントの順序がおかしくなる可能性があります。

### ビジョン

- すべてのビジョンが所持 / 未所持で表示されます。
- **選択項目に適用**: 所持しているビジョンの覚醒ポイントを変更します。
- **選択した未所持ビジョンを入手**: 未所持のビジョンを所持リストに登録します。**実験的な機能です。**
  - アイテムと同様に空きスロットが必要です。ゲーム内で新しいビジョンを普通に入手すると空きスロットができます。
  - シンクロポイントは空の状態で入ります。登録後は必ず新しいスロットにセーブして確認してください。

### バトル

**戦闘アイテムドロップ率** — すべての敵に一括で適用されます。

| 項目 | 説明 |
|---|---|
| 倍率スライダー | 通常・レアそれぞれ ×1〜×10。「元の確率 × 倍率」になり、上限は100%です。 |
| 必ずドロップ (100%) | ドロップアイテムが設定されている敵はすべて100%になります。 |
| ドロップ率を初期値に戻す | 元の確率に戻します。 |

**戦闘計算の数値** — 値を入力して **適用**。各欄の横に初期値が表示されます。

- 味方 / 敵の先制攻撃率、逃走確率の補正、盗むのレアアイテム率
- ノーダメージボーナスEXP倍率、ブレイクフィニッシュボーナスのギル倍率、オーバーキルボーナスのAP倍率
- クリティカル / ブレイクのダメージ倍率、全体ダメージ係数 (味方・敵共通)
- リミットゲージの増加量、1戦闘あたりのビジョン召喚回数
- **先制攻撃 100%**: 味方100%、敵0%に一括設定します。
- **初期値に戻す**: すべての値を元に戻します。

## 困ったときは

| 症状 | 対処 |
|---|---|
| `接続失敗: … プロセスが見つかりません` | ゲームを起動してから **ゲームに接続** を押してください。 |
| `プロセスを開けません` | トレーナーを **管理者として実行** してみてください。 |
| `セーブデータがまだロードされていません` | ゲームでセーブをロードしてからもう一度試してください。 |
| 名前がおかしい、別の言語で表示される | **名前を再読込** を押してください。 |
| ゲームを再起動したら動かなくなった | **ゲームに接続** をもう一度押してください。 |
| ウイルス対策ソフトが実行ファイルをブロックする | 他のプログラムのメモリを読み書きするツールのため、誤検知されることがあります。例外に登録するか、ソースから実行してください。 |
| ゲームのパッチ後に接続できない | 場所は実行時に名前で探す方式なので基本的にはそのまま動きますが、構造が大きく変わった場合は修正が必要です。 |

## 実行ファイルの隣に作られるファイル

削除しても、次回の実行時に作り直されます。

| ファイル | 内容 |
|---|---|
| `names_cache.json` | ゲームから読み取った名前 (次回以降の起動を速くするための保存) |
| `drop_defaults.json` | ドロップ率の元の値 (初期値の復元用) |
| `lang.txt` | 選択した画面の言語 (`ko`、`en`、`ja`) |

## 画面の言語

- ウィンドウ上部の **言語メニュー** で 한국어 / English / 日本語 を選ぶと、すぐに切り替わります。オンにしている設定 (エンカウント、ドロップ率など) はそのまま維持されます。
- 初回起動時は Windows の表示言語に合わせて自動的に決まります (韓国語・日本語以外は英語)。
- アイテム名・キャラクター名は、画面の言語に関係なく **ゲームが動作している言語** で表示されます。

## ソースから実行する (任意)

Python 3.10 以降が必要です。

```
pip install "flet[all]"
python trainer.py
```

実行ファイルを自分でビルドする場合は、`pip install pyinstaller` のあと `python build_exe.py` を実行します。

## 制限事項

- エンカウントの調整、ドロップ率の変更、ビジョンの登録は、メモリ上の値が変わるところまでしか確認しておらず、実際のプレイでの効果は十分に検証されていません。
- アイテム・ビジョンの新規登録は、空きスロットがあるときだけ可能です (上記参照)。
- 戦闘中の無敵やワンキルの機能はありません。
- アーティファクト19種、だいじなもの4種、装備1種はゲーム内に韓国語のテキストがなく、韓国語画面では作者による訳名で表示されるため、ゲーム内の表記と異なる場合があります。
- Steam版シングルプレイ専用です。
