# FINAL FANTASY RESONANCE 트레이너

[English](README.md) | **한국어** | [日本語](README.ja.md)

Steam판 FINAL FANTASY RESONANCE(싱글플레이)용 트레이너입니다. 실행 중인 게임의 메모리에서 세이브 데이터와 데이터 테이블 값을 읽고 씁니다. 게임 파일과 실행 코드는 건드리지 않습니다.

## 실행 환경

| | |
|---|---|
| 운영체제 | Windows 10 / 11, **64비트(x64)** — Windows 11에서 테스트 |
| 게임 | **FINAL FANTASY RESONANCE Steam 버전** (싱글플레이) |
| 추가 설치 | `FFR-Trainer.exe`는 필요 없음. Python은 소스로 실행할 때만 필요합니다. |

- 다른 플랫폼이나 Steam이 아닌 다른 스토어 버전은 지원하지 않습니다.
- 32비트 Windows와 ARM용 Windows는 지원하지 않습니다.
- 게임이 실행 중이고 세이브가 로드된 상태여야 트레이너가 연결됩니다.

## 시작하기

1. 게임을 실행하고 **세이브를 로드**합니다 (타이틀 화면 이후).
2. `FFR-Trainer.exe`를 실행합니다.
3. 창 위쪽에 `연결됨 (PID …)`이 나오면 준비 완료입니다.
   - 처음 실행할 때는 한국어 이름을 읽느라 몇 초 걸립니다. 두 번째부터는 바로 뜹니다.
   - 게임보다 트레이너를 먼저 켰다면 게임을 켠 뒤 **게임에 연결**을 누르세요.

| 위쪽 버튼 | 기능 |
|---|---|
| 게임에 연결 | 게임을 다시 찾아 연결합니다. 게임을 껐다 켠 뒤에 누릅니다. |
| 새로고침 | 화면의 값을 게임의 현재 값으로 다시 읽습니다. |
| 이름 다시 읽기 | 아이템·캐릭터 이름을 게임에서 다시 읽어옵니다. 게임 패치 뒤나 게임 언어를 바꾼 뒤 이름이 이상할 때 씁니다. |
| 언어 메뉴 | 화면 언어를 한국어 / English / 日本語 중에서 고릅니다. 바로 적용되고 다음 실행에도 유지됩니다. |

## 꼭 알아둘 점

- **저장은 게임 안에서** 해야 변경 내용이 남습니다. 만일을 위해 기존 세이브를 덮어쓰지 말고 **다른 슬롯에 저장**하세요.
- 값을 바꾼 뒤 게임 화면에 바로 안 보이면 **메뉴를 닫았다 다시 열어** 보세요.
- `전투` 탭의 값(드랍 확률, 전투 계산 수치)은 세이브에 남지 않습니다. **게임을 끄면 원래대로** 돌아가므로 켤 때마다 다시 적용해야 합니다.
- 목록에서는 **행을 클릭하면 선택, 다시 클릭하면 해제**됩니다. 여러 행을 차례로 클릭하면 여러 개가 선택됩니다.

## 탭별 기능

### 일반

| 항목 | 설명 |
|---|---|
| 소지금 | 값을 입력하고 **적용**. **최대**는 9,999,999 길. |
| 소지금 고정 | 켜 두면 소지금이 입력한 값 아래로 내려가지 않습니다. |
| 난이도 | Easy / Normal / Expert 중에서 골라 **적용**. |
| 랜덤 인카운터 끄기 | 켜 두는 동안 필드에서 적과 마주치지 않게 합니다. |
| 인카운터 확률 | 0~300% 슬라이더. 100%가 기본, 300%는 3배 자주. **100%로** 버튼으로 복원. |

- 인카운터 기능은 **필드에 있을 때만** 적용됩니다. 옆에 `적용 중` 또는 `필드 대기 중`이 표시됩니다.
- 스토리 이벤트 전투와 보스전은 막지 않을 것으로 보입니다.
- "끄기"가 슬라이더보다 우선합니다.

### 캐릭터

목록에서 캐릭터를 클릭하면 아래 편집 칸에 현재 값이 채워집니다.

| 항목 | 설명 |
|---|---|
| 레벨 | 입력한 레벨에 해당하는 경험치로 맞춥니다. |
| 경험치 | 경험치를 직접 입력합니다. |
| 현재 HP / MP | 현재 HP·MP를 바꿉니다. |
| 스탯 영구 보너스 | 최대 HP, 최대 MP, 공격, 방어, 지능, 정신, 민첩에 더해지는 영구 보너스입니다. |

- 레벨·경험치를 바꾼 뒤에는 **저장 후 다시 로드하거나 전투를 한 번** 치러야 능력치에 반영됩니다.

### 아이템

- **보기**: 보유 중 / 전체 / 소모품 / 무기 / 방어구 / 악세서리 / 중요품 / 아티팩트
- **검색**: 이름 일부나 ID로 찾습니다.
- **선택 항목에 적용**: 선택한 아이템의 수량을 입력한 값(1~99)으로 맞춥니다.
- **보유 소모품 전부 적용**: 가진 소모품 전부를 한 번에 맞춥니다.

**미보유 아이템 등록** — 흐린 글씨로 표시된 미보유 아이템도 선택해서 적용하면 새로 등록됩니다. 단, 조건이 있습니다.

- 오른쪽 위의 **"새로 등록 가능한 빈 슬롯"** 수만큼만 등록할 수 있습니다.
- 게임을 방금 로드한 상태에서는 보통 **0개**입니다.
- 빈 슬롯을 만들려면 게임에서 **아직 갖고 있지 않은 종류의 아이템을 하나** 얻으세요 (상점 구매 등). 그러면 게임이 인벤토리 공간을 늘려 빈 슬롯이 수십 개 생깁니다.
- 중요품과 아티팩트는 수량이 항상 1개로 들어갑니다.
- **중요품**은 스토리 진행 조건으로 쓰일 수 있어 등록 전에 확인 창이 뜹니다. 이벤트 순서가 꼬일 수 있으니 주의하세요.

### 비전

- 전체 비전이 보유 / 미보유로 표시됩니다.
- **선택 항목에 적용**: 보유한 비전의 각성 포인트를 바꿉니다.
- **선택한 미보유 비전 획득**: 미보유 비전을 보유 목록에 등록합니다. **실험적인 기능**입니다.
  - 아이템과 마찬가지로 빈 슬롯이 있어야 합니다. 게임에서 새 비전을 하나 정상적으로 획득하면 빈 슬롯이 생깁니다.
  - 싱크로 포인트가 비어 있는 상태로 들어갑니다. 등록 후에는 반드시 새 슬롯에 저장해서 확인하세요.

### 전투

**전투 아이템 드랍 확률** — 모든 적에 한꺼번에 적용됩니다.

| 항목 | 설명 |
|---|---|
| 배율 슬라이더 | 일반·레어 각각 ×1~×10. "원래 확률 × 배율"이 되며 100%가 상한입니다. |
| 항상 드랍 (100%) | 드랍 아이템이 설정된 적은 모두 100%가 됩니다. |
| 드랍 확률 기본값으로 | 원래 확률로 되돌립니다. |

**전투 계산 수치** — 값을 입력하고 **적용**. 옆에 기본값이 표시됩니다.

- 아군 / 적 선제공격 확률, 도주 확률 보정, 훔치기 레어 확률
- 노 대미지 보너스 EXP 배율, 브레이크 피니시 보너스 길 배율, 오버킬 보너스 AP 배율
- 크리티컬 / 브레이크 대미지 배율, 전체 대미지 계수 (아군·적 공통)
- 리미트 게이지 증가량, 전투당 비전 소환 가능 횟수
- **선제공격 100%**: 아군 100%, 적 0%로 한 번에 설정합니다.
- **기본값으로**: 전부 원래 값으로 되돌립니다.

## 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| `연결 실패: … 프로세스를 찾을 수 없습니다` | 게임을 먼저 실행한 뒤 **게임에 연결**을 누르세요. |
| `프로세스를 열 수 없습니다` | 트레이너를 **관리자 권한으로 실행**해 보세요. |
| `세이브 데이터가 아직 로드되지 않았습니다` | 게임에서 세이브를 로드한 뒤 다시 시도하세요. |
| 이름이 이상하거나 다른 언어로 나옴 | **이름 다시 읽기**를 누르세요. |
| 게임을 껐다 켰더니 동작하지 않음 | **게임에 연결**을 다시 누르세요. |
| 백신이 실행 파일을 차단함 | 다른 프로그램의 메모리를 읽고 쓰는 도구라 오진될 수 있습니다. 예외로 등록하거나 소스 실행 방식을 쓰세요. |
| 게임 패치 뒤 연결 실패 | 위치를 실행 중에 이름으로 찾는 방식이라 대체로 그대로 동작하지만, 구조가 크게 바뀌면 수정이 필요합니다. |

## 함께 생기는 파일

실행 파일과 같은 폴더에 만들어집니다. 지워도 다음 실행 때 다시 만들어집니다.

| 파일 | 내용 |
|---|---|
| `names_cache.json` | 게임에서 읽어 온 이름 (다음 실행을 빠르게 하기 위한 저장본) |
| `drop_defaults.json` | 드랍 확률 원래 값 (기본값 복원용) |
| `lang.txt` | 고른 화면 언어 (`ko`, `en`, `ja`) |

## 화면 언어

- 창 위쪽의 **언어 메뉴**에서 한국어 / English / 日本語를 고르면 바로 바뀝니다. 켜 둔 설정(인카운터, 드랍 확률 등)은 그대로 유지됩니다.
- 처음 실행할 때는 Windows 표시 언어에 맞춰 자동으로 정해집니다 (한국어·일본어가 아니면 영어).
- 아이템·캐릭터 이름은 화면 언어와 상관없이 **게임이 실행 중인 언어**로 표시됩니다.

## 소스로 실행하기 (선택)

Python 3.10 이상이 필요합니다.

```
pip install "flet[all]"
python trainer.py
```

- `트레이너 실행.bat`을 더블클릭해도 됩니다.
- `trainer_tk.py`는 추가 설치가 필요 없는 이전 화면(tkinter) 버전입니다. 드랍 확률 조정과 언어 선택은 들어 있지 않습니다.
- 배포용 실행 파일을 직접 만들려면 `pip install pyinstaller` 후 `python build_exe.py`를 실행하세요.

## 한계

- 일부 실제 플레이에서의 효과는 충분히 검증되지 않았습니다.
- 아이템·비전 신규 등록은 빈 슬롯이 있을 때만 가능합니다 (위 설명 참고).
